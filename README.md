# Megano — итоговый дипломный проект (интернет-магазин)

## Развёртывание

1. `git clone <ссылка на репозиторий>` — команды ниже выполняются из корня склонированного репозитория
2. Скопировать `.env.example` в `.env` и заполнить значения
3. Создать и активировать виртуальное окружение, затем **из корня репозитория** установить зависимости и пакет `frontend`: `pip install -r requirements.txt` (путь до архива фронтенда в `requirements.txt` — относительный, из другой директории установка не найдёт файл)
4. `python manage.py migrate`
5. `python manage.py runserver 0.0.0.0:8000`

Раздача статики (CSS/JS/картинки фронтенда) и медиафайлов настроена так, что работает сразу после `runserver`, независимо от значения `DJANGO_DEBUG` — `collectstatic` и отдельный веб-сервер под статику не требуются.

Раздел будет дополняться по ходу разработки.
